
- flashcard_dir <br/>
the location where your flashcard lists are stored.  <br/>
    
- show_keybinds_help <br/>
whether to show how to access keybinds in main menu on startup. defaults to true <br/>

- auto_accent <br/>
whether to convert backticks before a vowel into an accent on the vowel. two backticks will escape the accent. <br/>
