A TUI program for studying flashcards, using the NCURSES library.

<h1> FEATURES: </h1>
- Create and edit flashcard sets from within the program <br />
- Good looking (IMO) UI <br />
- Study flashcards <br />
- Flashcards with multiple definitions <br />

<h2> Quiz types: </h2>
- Flip flashcards <br />
- Typing quizes <br />
- Multiple choice quizes <br />

<h1> TO BE ADDED:</h1>

<h1> Installation</h1>
- assuming you have all dependencies, just run:
```
$ make
```
- to bootstrap a basic config file and an example vocab list, run:
```
$ make bootstrapConfig
```


<h1> DEPENDENCIES:</h1>
- ncurses <br />
- msys2 (windows only)
