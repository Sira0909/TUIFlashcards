<h1> Incompatabilities </h1>
summary of differences on Operating Systems

<h2> Linux </h2>
- all features should be supported (this is the prefered OS for using TUIFlashcards right now)
- development and testing are primarily done on Arch Linux, so I know everything is supported there. Most other linux distros should work.

<h2> windows </h2>
- almost all features are supported. exceptions:
- windows terminal does not support changing colors
- when adding definitions, the new column does not appear until you move
- animations are SIGNIFICANTLY faster, as I don't have access to poll
- there may be more, so I recommend using a different OS for now.
